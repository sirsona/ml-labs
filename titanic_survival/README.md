# Titanic Survival Prediction

A machine learning classification project that predicts whether a passenger survived the
Titanic disaster.

## Project Overview

This project uses the Titanic dataset to build a binary classification model.

Target Variable:

- `0` -> Did not survived
- `1` -> Survived

The Project demonstrate a complete machine learning workflow including:

- Data inspection
- Exploratory Data Analysis (EDA)
- Feature engineering
- Missing value imputation
- Feature scaling
- Logistic Regression
- Model evaluation
- Cross-validation
