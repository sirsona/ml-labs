# Housing Price Prediction (Regression Project)

## Overview

This project predicts house prices using machine learning regression model based on
features such as square footage, number of rooms, house age, and distance to the city.

### Dataset

The dataset contains 10,000 rows and 5 columns

| Feature              | Description                   |
| -------------------- | ----------------------------- |
| square_feet          | Size of the house             |
| num_rooms            | Number of rooms               |
| age                  | Age of the house              |
| distance_to_city(km) | Distance from city center     |
| price                | Target variable (house price) |
